# 两台电脑，玩同一局 4399 双人游戏

> **Sunshine + Moonlight + AutoHotkey —— 把「同屏双人」拆到两台电脑上**
> Play local co-op web games on two separate PCs.

---

## 这是什么

4399 上的双人小游戏（造梦西游 3、拳皇、雪人兄弟、魂斗罗……）默认都是**两个人挤在一台电脑前共用一个键盘**：1P 用 `WASD`，2P 用方向键。

这个项目让你和朋友**各坐一台电脑、各看各的屏幕、各按各的键盘**，玩同一局游戏 —— 而且**两台电脑装的软件完全一样，谁当主机、谁当客户端随时互换**。

全程只用三个免费开源软件，不用写一行代码，不用买任何东西。

---

## 效果

```
        ┌──────────────────┐                    ┌──────────────────┐
        │   主机（A 的电脑）  │                    │  客户端（B 的电脑）│
        │                  │                    │                  │
        │   游戏在这里跑     │   ──── 画面 ────▶   │   Moonlight      │
        │                  │                    │   看到 A 的屏幕   │
        │  1P ← A 的 WASD   │                    │                  │
        │  2P ← 远程按键     │   ◀─── 按键 ────    │   AHK 把 B 的     │
        │                  │                    │   WASD 转成方向键  │
        │   Sunshine        │                    │                  │
        └──────────────────┘                    └──────────────────┘
```

- **A 的键盘** → 直接玩 1P（WASD）
- **B 的键盘** → 按键传回主机后，被当成 **2P** 的方向键
- 游戏**完全不知道有网络存在**，它以为两套键盘都插在同一台电脑上

---

## 原理（一句话）

游戏只跑在**一台**电脑上。这台电脑的画面实时传给另一台，另一台的按键再传回来、注入成本地键盘事件。

所以「画面传输 + 按键回传」是**同一个工具的两件事** —— 用现成的串流软件一次搞定，不需要自己写代码。

## 快速开始

### 1. 网络（最关键，先做对）

**两台必须连同一个 WiFi。**
如果两台各自的网线接在不同的路由器上，那条有线路径是互不通的 —— 请改用同一个 WiFi。

> **有线 + WiFi 同时开着的情况**：Windows 会同时用两个网卡。如果两者在**同一个网段**（比如都是 `192.168.1.x`），路由会打架、串流连不上。**玩游戏时把有线网卡临时禁用最省事**：右下角网络图标 → 网络和 Internet 设置 → 高级网络设置 → 找到「以太网」→ 禁用。玩完再启用。

**验证互通（必做）**

1. 主机上 `Win + R` → 输入 `cmd` → 敲 `ipconfig`，找到 **无线局域网适配器 WLAN** 下的 **IPv4 地址**（形如 `192.168.2.35`），记下来；
2. 客户端上开 `cmd`，敲 `ping 192.168.2.35`（换成上面记的 IP）。
   - 有回包（`时间=1ms`）→ ✅ 通了
   - 「请求超时 / 无法访问目标主机」→ ❌ 没通，检查是不是同一个 WiFi

**防火墙放行（漏了就连不上）**

Windows 常把 WiFi 识别成「公用网络」而拦掉 Sunshine：

- 控制面板 → Windows Defender 防火墙 → 允许应用或功能通过防火墙 → 找到 **Sunshine** → **「专用」和「公用」两列都勾上**；
- 或者把当前 WiFi 的网络配置文件改成「**专用网络**」。

### 2. 安装 Sunshine（两台都装）

1. 运行 `Sunshine-Windows-AMD64-installer.msi`，一路下一步；
2. 装完自动在后台运行，右下角托盘有图标；
3. 浏览器打开 `https://localhost:47990`（提示「不安全」就点「高级 → 继续访问」）；
4. 首次进入**设置一个用户名和密码**（自己随便设，记好）；
5. 进 **Configuration** 配编码器（见下一节）。

### 3. 编码设置

Sunshine 的 Configuration 页，**左边 `ENCODERS` 那一栏就是编码器选择**：

| 界面上的英文 | 中文含义 | 怎么选 |
|---|---|---|
| **NVIDIA NVENC Encoder** | 英伟达显卡硬件编码 | N 卡选这个 |
| Intel QuickSync Encoder | 英特尔核显编码 | Intel 核显选这个 |
| AMD AMF Encoder | AMD 显卡编码 | A 卡选这个 |
| Software Encoder | 纯软件编码 | ❌ 太慢，别用 |

**右边那些参数（Performance preset、Split frame encoding 等）全部保持默认**，不用动。

**编码格式（H.264 / HEVC）不在 Sunshine 里选，在客户端 Moonlight 的「视频编解码器」里选。** 默认「自动」即可。

> ⚠️ **不要选 AV1**：新显卡（如 RTX 4060）支持 AV1 编码，但老显卡（如 GTX 1660Ti）**不能解码 AV1**，客户端会黑屏。统一用 **H.264 或 HEVC** 最安全。

其他建议：分辨率 **1920x1080**、帧率 **60**、码率 **20~40 Mbps**（局域网）、V-Sync 和 HDR 关掉（减延迟）。

### 4. 安装 Moonlight（两台都装）

运行安装包，装完打开。

### 5. 配对

1. Moonlight 会**自动搜索**局域网主机（主机上 Sunshine 开着就会显示）；
2. 搜不到就点右上角 `+`，手动输入主机的 WiFi IP；
3. 点主机名字 → 主机 Sunshine 网页会弹出 **PIN 码输入框** → 把 Moonlight 显示的 **4 位数字**填进去 → 配对完成；
4. 点主机名开始串流，客户端就能看到主机画面了。

### 6. 键位映射（**只在客户端那台**用）

游戏固定用 **1P = W A S D**、**2P = 方向键**。客户端的键盘也只有 WASD，直接按会和 1P 撞车。所以用 AutoHotkey 把客户端的按键**转成游戏 2P 认的键**。

**先查游戏里的真实键位**：打开游戏 → **设置 → 按键设置**，看清 2P 的移动 / 攻击 / 跳跃分别是什么键（本项目的预设按常见的「2P = 方向键 + 小键盘」配置，以你游戏里显示的为准）。

**运行脚本**：把 `2P按键映射器.ahk` 放到客户端电脑上双击（需先装 AutoHotkey v2）。任务栏出现**绿色 H 图标**即生效。

**热键：**

| 热键 | 作用 |
|---|---|
| `Ctrl + Alt + 1~9` | 切换预设 |
| `Ctrl + Alt + 0` | **关闭映射**（这台电脑改当主机时按） |
| `Ctrl + Alt + R` | 重新加载（改完预设表后按） |

**内置预设：**

| 编号 | 名称 | 内容 |
|---|---|---|
| 1 | 造梦西游 3 | WASD → 方向键，9 个功能键 → 小键盘 / 主键盘 0（见下表） |
| 2 | 街机 / 格斗 | WASD → 方向键，J/K/L/U → 小键盘 1/2/3/4 |
| 3 | 右手布局 | IJKL → 方向键 |
| 4 | 仅移动 | WASD → 方向键 |
| 5 | 自定义 | 自己改 |

**预设 1（造梦西游 3）完整键位对照：**

| 你按的键 | 游戏里 2P 收到的键 |
|---|---|
| W / A / S / D | ↑ / ← / ↓ / → |
| J | 小键盘 1 |
| K | 小键盘 2 |
| U | 小键盘 3 |
| I | 小键盘 4 |
| O | 小键盘 5 |
| Y | 小键盘 6 |
| H | 小键盘 7 |
| L | 小键盘 8 |
| **空格** | **主键盘 0** |

### 7. 开始游戏

**主机：**
1. 确认 Sunshine 在运行（托盘有图标）；
2. 打开游戏，进全屏，**点一下游戏画面**让它获得焦点；
3. 用自己的 **WASD** 玩 = **1P**。

**客户端：**
1. 打开 Moonlight，连上主机，看到画面；
2. 双击运行 `2P按键映射器.ahk`；
3. 按自己键盘的 **WASD** = **2P**。

**角色互换**：原来当客户端的想当主机 → 打开 Sunshine 和游戏即可（记得按 `Ctrl+Alt+0` 关掉 AHK 映射）。

## 换游戏怎么改键（不用求人）

脚本开头的预设表**就是给你改的**：

```ahk
    ; 预设 1
    1, {name: "造梦西游3（WASD→方向键，9 个功能键）", map: Map(
        "w", "Up",      "a", "Left",    "s", "Down",    "d", "Right",
        "j", "Numpad1", "k", "Numpad2", "h", "Numpad7", ...
    )},
```

格式是**一对一对**写：`"你按的键", "游戏里对应的键",`

- **左边** = 你键盘上的键
- **右边** = 游戏 2P 真正认的键（去游戏的「按键设置」里抄）

改完存盘，按 `Ctrl + Alt + R` 重新加载即可，**不用重装、不用重启、不用找别人改**。

### 键名对照表

| 你想按的键 | 这里写 |
|---|---|
| 空格 | `Space` |
| 回车 | `Enter` |
| Shift | `Shift` |
| Ctrl | `Ctrl` |
| Alt | `Alt` |
| Tab | `Tab` |
| Esc | `Escape` |
| 方向键 | `Up` / `Down` / `Left` / `Right` |
| 字母 | 直接写 `a` `b` `c` … |
| **主键盘**数字 | 直接写 `1` `2` `3` … |
| **小键盘**数字 | `Numpad0` ~ `Numpad9` |
| 小键盘减号 | `NumpadSub` |
| 小键盘回车 | `NumpadEnter` |

> ⚠️ 注意区分：`1` 是 **主键盘**的 1，`Numpad1` 是 **小键盘**的 1，写错游戏就不认。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| Moonlight 搜不到主机 | ① 两台不在同一 WiFi；② Sunshine 没运行；③ 防火墙没放行；④ 手动 `+` 输 IP |
| 连上了但黑屏 | 编码格式选了 AV1 而客户端不支持 → 改成 HEVC 或 H.264 |
| 画面卡、延迟大 | ① 别连 2.4GHz，连 5GHz；② 码率降到 15~20 Mbps；③ 关掉占网速的程序；④ 靠近路由器 |
| 按键没反应 | ① 主机游戏窗口没获得焦点（点一下游戏画面）；② 客户端 AHK 没开；③ 游戏 2P 键位和脚本映射不一致 |
| 2P 按了却是 1P 在动 | AHK 映射没生效，或映射的键和游戏设置对不上 |
| 两台 IP 都是 `192.168.1.x` 连不上 | 有线与 WiFi 撞网段 → 禁用有线网卡 |
| 装 Sunshine 提示「处理器类型不支持」 | 下错架构了。普通电脑（Intel / AMD 的 CPU）都下 **AMD64** 版，别下 ARM64 |

## 这个方案还能玩哪些游戏

**只要一个游戏「在一台电脑上能双人同屏」（两个人共用一个键盘），就能用同样的方法拆到两台电脑。**

适合的（4399 双人同屏类）：造梦西游系列、拳皇 / 街霸类格斗、双截龙 / 热血系列、魂斗罗、雪人兄弟、坦克大战、炸弹人、合金弹头（部分版本）、西游释厄传……

判断标准：**看它是不是「1P 2P 共用一个键盘」的双人模式。**

**不适用的**：游戏本身就带联网对战的（两人各开房间联机）—— 那种直接联机就行，不需要这套。

**额外好处**：这套工具等于给你俩配了个「低延迟远程桌面」，还能用来远程看/操作对方电脑、一起看同一个视频。
